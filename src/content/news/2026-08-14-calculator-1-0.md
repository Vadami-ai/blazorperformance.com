---
title: "Capacity Calculator 1.0 released as open source"
date: 2026-08-14
---

The Blazor Server Capacity Calculator is now open source under MIT. The release
restructures the tool into inspectable ES-module source with a pure calculation
core, precompiled to ~200 KB of production JavaScript. Grab the single-file
standalone build from GitHub Releases for offline use, or run it
[right here on the site](/tools/capacity-calculator/).
